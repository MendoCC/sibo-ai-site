# SIBO AI — webbplats

Statisk sajt för `siboai.app`, publicerad via GitHub Pages.

- `index.html` — startsida
- `privacy.html` — integritetspolicy (engelska + svenska), genererad ur
  `docs/PRIVACY-POLICY.md` i app-repot så att de inte kan glida ifrån varandra
- `support.html` — kontakt, radering av uppgifter, prenumerationshantering
- `styles.css` — egen CSS, inga externa typsnitt
- `CNAME` — `siboai.app`

## Inga tredjepartsresurser

Ingen analytics, inga cookies, ingen JS, inga CDN:er eller externa typsnitt. Det är
ett hårt krav för det här projektet, inte en preferens.

## Uppdatera policyn

Generera om från app-repot (enskilt skript), committa och pusha. Fälten markerade
`ATT FYLLA I` (kontakt-e-post, registrerad adress) är medvetet synliga tills de är ifyllda.
